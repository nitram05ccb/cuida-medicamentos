# Cuida — app instalable para iPhone y Android

Cuida es una aplicación web progresiva (PWA). No requiere registro ni inicio de sesión: la lista de medicamentos y el historial de tomas se guardan en el almacenamiento local del navegador de cada dispositivo. No hay sincronización entre dispositivos.

## Publicarla con GitHub Pages

1. Crea un repositorio en GitHub y sube el contenido de esta carpeta, incluida la carpeta `.github`.
2. En el repositorio, abre **Settings → Pages** y selecciona **GitHub Actions** como origen.
3. La acción incluida publicará Cuida cada vez que actualices la rama `main`. Cuando termine, copia el enlace HTTPS que aparece en **Settings → Pages**.
4. Abre ese enlace en el móvil. GitHub Pages sirve la web con HTTPS, necesario para el modo instalable y el uso sin conexión.

## Añadir al inicio

- **iPhone:** abre el enlace en Safari, toca **Compartir** y elige **Añadir a pantalla de inicio**.
- **Android:** abre el enlace en Chrome y toca **Instalar** en Cuida o **Añadir a pantalla de inicio** en el menú del navegador.

Los datos de ejemplo pueden sustituirse por las pautas indicadas por el profesional de salud. Si se borran los datos del navegador o se cambia de dispositivo, el historial local no se transfiere.
