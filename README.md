# Cuida — app instalable para iPhone y Android

Cuida es una aplicación web progresiva. No requiere registro ni inicio de sesión. Los medicamentos y el historial se guardan en el almacenamiento local del navegador de cada dispositivo; no se envían a GitHub ni se sincronizan entre móviles.

El sitio web es público para que puedas abrirlo desde tus dispositivos. El contenido público es la aplicación, no los datos introducidos al usarla.

## Activar la publicación con GitHub Pages

1. Abre **Settings → Pages** en este repositorio.
2. En **Build and deployment**, selecciona **GitHub Actions** como origen.
3. Espera a que finalice el flujo **Deploy Cuida to GitHub Pages**. El enlace HTTPS aparecerá en esa misma sección.
4. Abre el enlace en el móvil.

La app necesita HTTPS para instalarse y guardar su interfaz para usarla sin conexión.

## Añadir a la pantalla de inicio

- **iPhone:** abre el enlace en Safari, toca **Compartir** y elige **Añadir a pantalla de inicio**.
- **Android:** abre el enlace en Chrome y toca **Instalar** dentro de Cuida o **Añadir a pantalla de inicio** en el menú.

Cada móvil guarda sus propios datos. Si borras los datos del navegador o cambias de dispositivo, no se transfiere el historial.
